# Acceso PRO gratuito temporal

Cuando la promoción de PRO gratuito está activa, las cuentas que cumplen los requisitos reciben las funciones PRO **sin coste, hasta nuevo aviso**. La página de precios y tu Cuenta muestran si la promoción está activa. Este artículo describe ese modo; no anuncia que ya se haya iniciado.

## Quién obtiene acceso

Necesitas una **cuenta registrada con un correo electrónico verificado**. Una cuenta que sigue siendo de invitado no cumple los requisitos, aunque hayas iniciado sesión con una frase de recuperación o una passkey.

Si empezaste sin correo, abre **Cuenta**, añade tu correo mediante el formulario para convertir la cuenta de invitado y confirma el código recibido. Añadir una dirección sin confirmarla no basta. La frase de recuperación y las passkeys siguen siendo tus métodos de acceso. Consulta [Crear una cuenta](/documentation/create-account).

El acceso PRO asignado manualmente conserva su vigencia actual. El acceso Enterprise y los permisos administrativos no cambian.

## Funciones y límites

Las cuentas elegibles pueden utilizar las funciones PRO actuales, incluida la facturación empresarial, las exportaciones, las estadísticas avanzadas, Stripe y las funciones de efectivo/tarjeta compatibles del punto de venta. El acceso gratuito no conecta una cartera ni una cuenta de Stripe por ti; sigue las instrucciones habituales. Las comisiones de Stripe y otros proveedores siguen aplicándose según sus condiciones.

La promoción utiliza los límites PRO habituales:

| Elemento | Límite PRO estándar |
| --- | --- |
| Tiendas | 3 por cuenta |
| Claves API de tienda | 3 claves activas por tienda |
| Claves API del panel | 3 claves activas por cuenta |
| Eventos con entradas | 3 por tienda |
| Empresas de facturación propias | 2, más espacios adicionales existentes o límites especiales aplicables a la cuenta |
| Direcciones Lightning alojadas y sorteos | Sin límite de cantidad PRO |
| Extracciones ISDOC | Límite básico existente de 20 por cuenta, más créditos adquiridos anteriormente |

Consulta el límite actual en tu cuenta y en la página de cada función. La promoción no reinicia las extracciones ISDOC utilizadas ni ofrece extracciones ilimitadas. Las empresas compartidas contigo no cuentan como empresas propias.

El acceso PRO no otorga la gestión de usuarios de tienda de Enterprise ni acceso a tiendas o empresas ajenas. Las invitaciones, los roles y la propiedad siguen aplicándose.

## Compras y facturación

Mientras este modo está activo, **las nuevas suscripciones PRO, las pruebas y las compras de crédito para la suscripción PRO están suspendidas**. También se suspenden las nuevas compras de espacios para empresas y paquetes de extracción ISDOC. La facturación de Enterprise no cambia.

El acceso gratuito no crea una suscripción, no consume tu prueba, no cambia tu rol ni genera cargos automáticos. Se conservan tu historial de facturación, los espacios comprados y los créditos sin usar. Por ello, Cuenta puede mostrar un plan de facturación Free junto con funciones PRO disponibles; son datos distintos.

Al alcanzar un límite, no puedes aumentarlo comprando un complemento suspendido. Los objetos existentes por encima del límite se conservan; la creación de otros sigue sujeta al límite aplicable. Si agotas el límite básico de ISDOC, puedes utilizar créditos ya comprados, pero no comprar nuevos paquetes.

## Duración y precios futuros

**No hay una fecha de finalización programada.** «Hasta nuevo aviso» no significa acceso de por vida. Volver a PRO de pago requeriría un anuncio independiente y condiciones publicadas. La promoción no se convierte automáticamente en una suscripción de pago.

Guarda una copia de tu frase de recuperación y sigue las instrucciones habituales de [Copia de seguridad y recuperación](/documentation/backup-and-recovery). Consulta [Planes y límites](/documentation/plans-and-limits) para conocer los planes base.
