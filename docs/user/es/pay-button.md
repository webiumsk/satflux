# Pay Button

Un **Pay Button** es un fragmento HTML para recibir Bitcoin o Lightning en su sitio, por ejemplo para propinas o donaciones.

## Crear un botón

1. Abra **Pay Button** en su tienda.
2. Elija el importe fijo o elegido por el cliente y la moneda.
3. Copie el HTML generado y péguelo en su página.

El visitante abre la pantalla de pago al pulsar el botón. Para una tienda completa, utilice la integración con WooCommerce en lugar de botones individuales.

## Correo del comprador y dirección de retorno

El **Correo del comprador** opcional identifica al cliente en la factura. No activa las notificaciones por correo al comercio. Configúrelas mediante las reglas de correo de la tienda.

La redirección del navegador debe ser una dirección HTTP o HTTPS completa, como `https://example.com/thanks?order=123`. Se rechazan las rutas relativas y otros esquemas de URL. Corrija las direcciones no válidas antes de copiar el código generado.
