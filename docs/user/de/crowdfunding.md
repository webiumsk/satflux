# Crowdfunding

Erstellen Sie eine Crowdfund-App in Ihrem Shop und geben Sie Beschreibung, Währung und Finanzierungsziel ein. Speichern Sie die Kampagne, bevor Sie die öffentliche Seite teilen.

## Wiederkehrende Ziele

Aktivieren Sie ein wiederkehrendes Ziel und geben Sie ein positives ganzzahliges Intervall in Stunden, Tagen, Wochen, Monaten oder Jahren ein. Ein Fünf-Tage-Intervall bleibt beispielsweise nach dem Speichern bei fünf Tagen. Wochenintervalle können beim erneuten Öffnen als entsprechende Anzahl von Tagen erscheinen.

Die Wiederholung benötigt ein Startdatum; lassen Sie es leer, verwendet das Formular die aktuelle Zeit. Intervalle außerhalb des unterstützten Kalenderbereichs werden abgelehnt. Ihr Entwurf bleibt zur Korrektur und zum erneuten Speichern erhalten. Deaktivieren Sie die Wiederholung für ein einmaliges Finanzierungsziel.
