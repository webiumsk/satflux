# Pay Button

Ein **Pay Button** ist ein HTML-Ausschnitt, mit dem Sie Bitcoin oder Lightning auf Ihrer Website empfangen, etwa für Trinkgeld oder Spenden.

## Schaltfläche erstellen

1. Öffnen Sie **Pay Button** in Ihrem Shop.
2. Wählen Sie einen festen oder vom Kunden bestimmten Betrag und die Währung.
3. Kopieren Sie das erzeugte HTML und fügen Sie es auf Ihrer Seite ein.

Beim Anklicken öffnet der Besucher die Zahlungsansicht. Für einen vollständigen Onlineshop verwenden Sie die WooCommerce-Integration anstelle einzelner Schaltflächen.

## Käufer-E-Mail und Rücksprungadresse

Die optionale **E-Mail des Käufers** identifiziert den Kunden auf der Rechnung. Sie aktiviert keine E-Mail-Benachrichtigungen an Händler. Richten Sie diese über die E-Mail-Regeln des Shops ein.

Die Browser-Weiterleitung muss eine vollständige HTTP- oder HTTPS-Adresse sein, etwa `https://example.com/thanks?order=123`. Relative Pfade und andere URL-Schemata werden abgelehnt. Korrigieren Sie ungültige Adressen, bevor Sie den erzeugten Code kopieren.
