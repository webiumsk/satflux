# Zahlungseinstellungen des Shops

## Zeitvorgaben

Die Shop-Einstellungen zeigen Zeitspannen in Minuten an:

- Rechnungsablauf und Anzeige-Timer erlauben **1 bis 34.560 Minuten**.
- Die Zahlungsüberwachung erlaubt **10 bis 34.560 Minuten**.

Dies sind Shop-Standardwerte. Änderungen heben weder eine bestehende Sperre für einen Wallet-Wechsel auf noch ändern sie Fristen älterer Rechnungen.

## Eigenes CSS

Eigene CSS-Links müssen vollständige HTTP- oder HTTPS-URLs sein. Korrigieren Sie nicht unterstützte Links vor dem Speichern.
