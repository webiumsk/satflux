# Platobné nastavenia obchodu

## Časové nastavenia

Nastavenia obchodu zobrazujú časy v minútach:

- Platnosť faktúry a časovač prijímajú **1 až 34 560 minút**.
- Monitorovanie platieb prijíma **10 až 34 560 minút**.

Ide o predvolené hodnoty obchodu. Ich zmena neodstráni existujúce pozastavenie zmeny peňaženky ani neprepíše termíny starších faktúr.

## Vlastné CSS

Odkazy na vlastné CSS musia používať úplnú HTTP alebo HTTPS URL. Nepodporovaný odkaz treba pred uložením opraviť.
