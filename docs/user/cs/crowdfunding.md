# Crowdfunding

V obchodě vytvořte aplikaci Crowdfund a zadejte její popis, měnu a cíl financování. Před sdílením veřejné stránky kampaň uložte.

## Opakovaný cíl

Zapněte opakovaný cíl a zadejte kladný celočíselný interval v hodinách, dnech, týdnech, měsících nebo letech. Například pětidenní interval zůstane po uložení pětidenní. Týdenní intervaly se po opětovném otevření mohou zobrazit jako odpovídající počet dnů.

Opakování vyžaduje počáteční datum; pokud jej necháte prázdný, formulář použije aktuální čas. Interval přesahující podporovaný rozsah kalendáře se odmítne. Rozpracované údaje zůstanou zachovány pro opravu a opětovné uložení. Vypnutím opakování ponecháte jednorázový cíl financování.
