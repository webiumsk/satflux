# Platební nastavení obchodu

## Časová nastavení

Nastavení obchodu zobrazují časy v minutách:

- Platnost faktury a časovač přijímají **1 až 34 560 minut**.
- Sledování plateb přijímá **10 až 34 560 minut**.

Jde o výchozí hodnoty obchodu. Jejich změna neodstraní existující pozastavení změny peněženky ani nepřepíše termíny starších faktur.

## Vlastní CSS

Odkazy na vlastní CSS musí používat úplnou HTTP nebo HTTPS URL. Nepodporovaný odkaz je třeba před uložením opravit.
