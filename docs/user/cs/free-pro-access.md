# Dočasný PRO přístup zdarma

Když je akce PRO zdarma aktivní, oprávněné účty získají PRO funkce **bezplatně, až do dalšího oznámení**. Na stránce Ceník a ve svém Účtu uvidíte, zda je akce aktivní. Tento článek popisuje tento režim; neoznamuje, že už byl spuštěn.

## Kdo získá přístup

Potřebujete **registrovaný účet s ověřeným e-mailem**. Účet, který je stále hostovský, není oprávněný, ani když jste se přihlásili obnovovací frází nebo passkey.

Pokud jste začali bez e-mailu, otevřete **Účet**, přidejte e-mail přes formulář pro povýšení hostovského účtu a potvrďte kód z e-mailu. Samotné zadání adresy nestačí. Obnovovací fráze a passkeys zůstávají způsoby přihlášení. Viz [Vytvořte si účet](/documentation/create-account).

Existující ručně přidělené PRO si zachovává aktuální platnost. Enterprise přístup a administrátorská oprávnění se nemění.

## Funkce a limity

Oprávněné účty mohou používat současné PRO funkce včetně firemní fakturace, exportů, pokročilých statistik, Stripe a podporovaných hotovostních/kartových funkcí pokladny. Bezplatný přístup za vás nepřipojí peněženku ani Stripe účet; postupujte podle běžných návodů. Poplatky Stripe a jiných poskytovatelů nadále platí podle jejich podmínek.

Akce používá běžné PRO limity:

| Položka | Standardní PRO limit |
| --- | --- |
| Obchody | 3 na účet |
| API klíče obchodu | 3 aktivní klíče na obchod |
| API klíče panelu | 3 aktivní klíče na účet |
| Vstupenkové události | 3 na obchod |
| Vlastněné fakturační firmy | 2, plus existující dodatečné sloty nebo platné výjimky účtu |
| Hostované Lightning adresy a tomboly | Bez PRO limitu počtu |
| Extrakce ISDOC | Existující základní limit 20 na účet, plus dříve zakoupené kredity |

Aktuální limit zkontrolujte v účtu a na stránce dané funkce. Akce neresetuje použité extrakce ISDOC ani nepřidává neomezenou extrakci. Firmy sdílené s vámi se nepočítají mezi firmy, které vlastníte.

PRO přístup vám nedává Enterprise správu uživatelů obchodu ani přístup k cizím obchodům či firmám. Existující pozvánky, role a vlastnictví nadále platí.

## Nákupy a fakturace

Během aktivního režimu jsou **nová PRO předplatná, zkušební období a nákupy kreditu na PRO předplatné pozastavené**. Pozastavené jsou také nové nákupy firemních slotů a balíčků extrakcí ISDOC. Fakturace Enterprise zůstává nezměněná.

Bezplatný přístup nevytváří předplatné, nečerpá zkušební období, nemění vaši roli ani vám automaticky nic neúčtuje. Existující historie plateb, zakoupené sloty a nepoužité kredity zůstávají zachované. Účet proto může zobrazovat fakturační plán Free a současně dostupné PRO funkce; jde o odlišné údaje.

Při dosažení limitu jej nemůžete zvýšit nákupem pozastaveného doplňku. Existující objekty nad aktuálním limitem zůstávají zachované; vytváření dalších podléhá příslušnému limitu. Po vyčerpání základního ISDOC limitu můžete použít existující zakoupené kredity, nové balíčky však nekoupíte.

## Trvání a budoucí ceny

**Datum ukončení není stanovené.** „Až do dalšího oznámení“ neznamená doživotní přístup. Návrat k placenému PRO by vyžadoval samostatné oznámení a zveřejněné podmínky. Akce se automaticky nezmění na placené předplatné.

Mějte zálohovanou obnovovací frázi a řiďte se běžným návodem [Záloha a obnova](/documentation/backup-and-recovery). Základní plány popisuje článek [Plány a limity](/documentation/plans-and-limits).
