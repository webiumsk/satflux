# Pay Button

**Pay Button** je HTML úryvek pro přijímání Bitcoinu nebo Lightning na vašem webu, například pro spropitné nebo dary.

## Vytvoření tlačítka

1. V obchodě otevřete **Pay Button**.
2. Nastavte pevnou nebo zákazníkem zvolenou částku a měnu.
3. Zkopírujte vygenerované HTML a vložte je na svou stránku.

Po kliknutí návštěvník otevře platební obrazovku. Pro plnohodnotný obchod použijte místo jednotlivých tlačítek integraci s WooCommerce.

## Email kupujícího a návratová adresa

Volitelný **Email kupujícího** identifikuje zákazníka na faktuře. Nezapíná emailová oznámení obchodníkovi. Ta nastavíte v emailových pravidlech obchodu.

Přesměrování prohlížeče musí být úplná HTTP nebo HTTPS adresa, například `https://example.com/thanks?order=123`. Relativní cesty a jiná schémata URL se odmítnou. Před kopírováním vygenerovaného kódu opravte neplatnou adresu.
