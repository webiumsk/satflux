# Crowdfunding

Create a Crowdfund app in your store, then enter its description, currency and funding goal. Save the campaign before sharing its public page.

## Recurring goals

Enable a recurring goal and enter a positive whole-number interval in hours, days, weeks, months or years. For example, a five-day interval remains five days after saving. Weekly intervals can appear as an equivalent number of days when reopened.

A start date is required for recurrence; if you leave it blank, the form uses the current time. An interval that exceeds the supported calendar range is rejected. Your draft stays available so you can correct it and save again. Disable recurrence to keep a single funding goal.
