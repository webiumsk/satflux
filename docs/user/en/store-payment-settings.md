# Store payment settings

## Payment timing

Store settings show durations in minutes:

- Invoice expiration and the display timer accept **1 to 34,560 minutes**.
- Payment monitoring accepts **10 to 34,560 minutes**.

These are store defaults. Changing them does not remove an existing wallet-change hold or rewrite the deadlines of earlier invoices.

## Custom CSS

Custom CSS links must use a complete HTTP or HTTPS URL. An unsupported link must be corrected before saving.
